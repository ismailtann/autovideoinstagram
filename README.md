# 🚀 AI Reels İçerik Fabrikası (Stoacı Motivasyon)

Bu proje; Google Gemini, ElevenLabs ve OpenAI Whisper teknolojilerini kullanarak tam otomatik, dikey (9:16) formatta motivasyon videoları üretir.

## 🛠️ Kurulum

Öncelikle bilgisayarınızda **Python** ve **FFmpeg** kurulu olmalıdır. Ardından gerekli kütüphaneleri şu komutla yükleyebilirsiniz:

```bash
pip install google-genai requests openai-whisper
